# 🏫 代課費計算與管理系統 ＋ 全校課表查詢系統 (雲端雙合一整合版)

本版本已將 **「2026全校課表查詢系統」** 與 **「代課費計算與管理系統」** 進行深度整合。
全系統採用 **單一 Google 試算表資料庫 ＋ 單一 Google Apps Script (GAS) Web App 部署架構**。
老師可隨時查課表、即時時鐘掌握課堂進度，並能**一鍵點擊課表直接跳轉申報代課**！

---

## 📁 GAS 線上部署檔案清單

在 Google 試算表內點選「擴充功能」➔「Apps Script」，請在左側檔案清單建立以下 5 個核心檔案並貼入對應內容：

| 檔案名稱 | 類型 | 功能說明 |
| :--- | :--- | :--- |
| **Code.gs** | 程式碼檔 (.gs) | 雙系統後端核心：路由控制、課表讀取 (getScheduleData)、代課紀錄寫入與月度結算 |
| **index.html** | HTML 檔 (.html) | **三合一系統入口首頁**：包含課表查詢、教師交接、行政核銷三大卡片門戶 |
| **timetable.html** | HTML 檔 (.html) | **全校課表查詢端**：班級/科任/專科教室三合一、即時時鐘、當前節次高亮、**一鍵申報代課** |
| **teacher.html** | HTML 檔 (.html) | **教師交接端**：請假交接、A4紙本列印、支援從課表帶入參數自動選取班級與勾選節次 |
| **admin.html** | HTML 檔 (.html) | **行政核銷端**：月度結算、金鑰雙重防護、課表矩陣檢視、印領清冊匯出備份 |

> 💡 備註：專案資料夾內亦包含本機 Python 核銷印領清冊腳本 (generate_voucher.py) 與範本 (印領清冊113.xlsx)。

## 📊 Google 試算表分頁結構設定

合併後，全校僅需維護**一份 Google 試算表**！請在試算表中建立或匯入以下工作表：

1. **班級課表**（已校正為 100% 無衝堂）：
   - 包含欄位：班級/教室、年級、星期 (如 星期一)、節次 (如 第1節)、時間、科目、上課老師、老師身份、導師、上課地點。
   - 可直接使用本目錄下 `課表分頁範本/班級課表.xlsx`（或 `全校課表匯入_五欄格式.csv`）匯入。
   - 系統已全面校正：**每位教師每一節次嚴格限制僅排一個班級**，完全杜絕一人同節多班衝堂！
2. **科任課表**：
   - 包含欄位：上課老師、職稱/專長、授課班級/教室、星期、節次、科目、上課地點。
   - 可直接使用本目錄下 `課表分頁範本/科任課表.xlsx` 匯入。
3. **專科教室課表** (或 專科教室課表(19間))：
   - 包含專科教室排課與借用時段。
   - 可直接使用本目錄下 `課表分頁範本/專科教室課表.xlsx` 匯入。
4. **System_Settings**：
   - 系統全域設定（學校名稱、鐘點費率、維護人員資訊、安全金鑰）。首次由行政端點擊儲存設定時會自動產生。
5. **YYYY-MM_總表 與 YYYY-MM_明細**：
   - 教師送出代課單時，系統會自動按月產生對應分頁。

## 🚀 3 分鐘快速部署步驟

1. 開啟您的 Google 試算表，點選上方選單 **「擴充功能」➔「Apps Script」**。
2. 將預設的 程式碼.gs 內容替換為本目錄的 **Code.gs**。
3. 點選左側「**+**」➔「**HTML**」，分別建立以下 4 個檔案並貼入對應內容：
   - 檔名輸入 `index`，貼入 index.html
   - 檔名輸入 `timetable`，貼入 timetable.html
   - 檔名輸入 `teacher`，貼入 teacher.html
   - 檔名輸入 `admin`，貼入 admin.html
4. 按 **Ctrl + S** 儲存全部檔案。
5. 點選右上角藍色按鈕 **「部署」➔「新增部署」**：
   - 種類選取：**「網頁應用程式」 (Web App)**
   - 說明：代課費計算與全校課表查詢整合系統
   - 執行身分：**「我」 (Me)**
   - 誰有存取權：**「所有人」 (Anyone)**
6. 點選「部署」並完成 Google 授權，複製系統產生的專屬網址！

## 💡 亮點特色：課表一鍵申報代課

在全校課表查詢端（?page=timetable）：
1. 點選任意班級或科任老師課表。
2. 課堂中會顯示「**👉 申報代課**」按鈕。
3. 點擊後，系統會自動跳轉至教師交接端，**並自動帶入所選班級、授課教師與當節節次打勾**，完全免除手動重填的麻煩！
