# 1. 開啟終端機並切換至資料夾
cd "/Users/tsai/Desktop/志益小工具/代課費計算系統"

# 2. 執行 Python 憑證生成腳本
python3 generate_voucher.py

* 執行後，腳本會自動讀取 JSON 資料，並產出一份符合行政核銷規格的 Word 橫式 A4 印領清冊（含表格線條與自動小計）。
