# 國小代課費計算與管理系統 (Google Apps Script Web App 雲端全整合版)

這是一套專為國小教務處與教師設計的**「代課費計算與管理系統」**。
現在已將 **前端網頁（首頁、教師端、行政端、CSS 樣式）與後端資料庫完整改寫整併至 Google Apps Script (GAS)**。

您只需要在 Google 試算表中建立 Apps Script 專案並進行「網頁應用程式部署」，就能獲得一個專屬的雲端網址，老師與行政人員直接點開網址即可操作，無需另外架設伺服器或設定複雜網址！

---

## 📁 專案檔案清單（GAS 對應檔案）

在 Google Apps Script 編輯器中，請建立以下 5 個檔案並貼入對應內容：

| 檔案名稱 | GAS 檔案類型 | 功能說明 |
| :--- | :--- | :--- |
| **`Code.gs`** | 程式碼檔 (.gs) | 後台資料庫邏輯、Web App 路由 (`doGet`/`doPost`)、直連 API |
| **`index.html`** | HTML 檔 (.html) | **系統入口門戶**（已內嵌完整 CSS，含教師端與行政端選單入口） |
| **`teacher.html`** | HTML 檔 (.html) | **教師交接端**（課表自動帶入、A4 紙本通知單列印、存檔） |
| **`admin.html`** | HTML 檔 (.html) | **行政核銷端**（月度代課節數統計、費用自動結算、Word 憑證 JSON 下載） |

*(本機輔助檔案)*：
* `styles.html` / `styles.css`：CSS 原始樣式備份。
* `generate_voucher.py`：本機 Word (.docx) / Excel (.xlsx) 核銷印領清冊自動生成腳本。
* `印領清冊113.xlsx`：核銷報表 Excel 格式範本。

## 🚀 快速部署步驟（3 分鐘完成）

### 第一步：建立 Google 試算表
1. 開啟您的 Google 雲端硬碟，新增一份「Google 試算表」（或使用學校既有範本）。
2. 在試算表下方新增一個名為 **`Class_Timetables`** 的分頁，填入學校課表：
   * **A 欄**：班級（例：`一甲`、`四甲`）
   * **B 欄**：星期（例：`1`、`2`、`3`、`4`、`5`）
   * **C 欄**：節次（例：`1`、`2`、`3`、`4`、`5`、`6`、`7`）
   * **D 欄**：科目（例：`國語`、`數學`）
   * **E 欄**：授課教師（例：`楊琬瑄`）

---

### 第二步：建立 Apps Script 檔案並貼入程式碼
1. 在該 Google 試算表上方選單，點選 **「擴充功能」➔「Apps Script」**。
2. 在左側「檔案」清單中建立並貼上以下檔案：
   * 點選預設的 `程式碼.gs`（可重新命名為 `Code.gs`），**貼上本專案的 `Code.gs` 內容**。
   * 點選 **「+」➔「HTML」**，輸入檔名 **`index`**，**貼上本專案的 `index.html` 內容**。
   * 點選 **「+」➔「HTML」**，輸入檔名 **`teacher`**，**貼上本專案的 `teacher.html` 內容**。
   * 點選 **「+」➔「HTML」**，輸入檔名 **`admin`**，**貼上本專案的 `admin.html` 內容**。
3. **設定安全金鑰**：
   * 開啟 `Code.gs`，找到第 21 行：
     ```javascript
     var SECRET_KEY = '請在此填入自訂的隨機安全金鑰密碼';
     ```
   * 將其修改為您自訂的一串密碼（例如：`Maming2026SecureKey`），此金鑰用於保護行政端資料。
4. 點選上方工具列的 **「儲存」圖示 (Ctrl + S)**。

---

### 第三步：發布部署為網頁應用程式 (Web App)
1. 點擊右上角藍色按鈕 **「部署」➔「新增部署」**。
2. 點擊齒輪圖示，選取 **「網頁應用程式」** (Web App)。
3. 設定如下：
   * **說明**：代課費計算系統
   * **執行身分**：選取 **「我」 (Me)**
   * **誰有存取權**：選取 **「所有人」 (Anyone)** *(確保教師免登入即可填報)*
4. 點擊 **「部署」**，依畫面提示完成 Google 帳號授權。
5. 複製系統產生的 **「網頁應用程式網址」** (URL)。

---

## 💻 網頁使用方式

部署完成後，您只需透過瀏覽器開啟複製的網頁應用程式 URL：

1. **入口首頁**：
   * 網址：`https://script.google.com/macros/s/.../exec`
   * 可自由選擇進入「教師交接端」或「行政核銷端」。
2. **教師交接端**：
   * 網址：`https://script.google.com/macros/s/.../exec?page=teacher`
   * 教師選擇日期、班級後，系統自動帶入課表與任課老師。勾選請假節次即可預覽 A4 紙本通知單，點擊「送出交接單」直接存入試算表！
3. **行政核銷端**：
   * 網址：`https://script.google.com/macros/s/.../exec?page=admin`
   * 首次使用請點右上角 **「齒輪設定」**，輸入您在 `Code.gs` 設定的 `SECRET_KEY` 金鑰。
   * 選擇結算月份後點選 **「從雲端同步資料」**，即可統計當月代課節數與金額，並可點選 **「1. 下載當月結算 JSON」**。

---

## 📄 印領清冊產生器使用說明

1. 在行政端確認資料無誤後，點選 **「下載當月結算 JSON」**。
2. 將下載的 `代課費系統備份_YYYY-MM.json` 放置於本機專案資料夾下（與 `generate_voucher.py`、`印領清冊113.xlsx` 同一目錄）。
3. 執行 Python 腳本：
   ```bash
   python generate_voucher.py
   ```
4. 系統將自動產出：
   * `YYYY年MM月_代課費印領清冊.docx` (橫式 A4 Word 清冊，可直接列印簽章核銷)
   * `115年MM月_代課費印領清冊.xlsx` (帶入統計數據的 Excel 報表)
