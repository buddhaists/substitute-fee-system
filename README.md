# 國小教師代課費計算與管理系統 ─ 公開部署與使用指南

這是一套為國小設計的**「代課費計算與管理系統」**，能自動化教師填報交接、雲端試算表儲存、行政月底核銷，並一鍵產生 Word/Excel 格式的代課費印領清冊。

## 系統架構
1. **[教師端] teacher.html**：供請假教師填寫代課日期、假別、班級、交接事項。
   - 手機可直接填寫，自動依校內課表帶入當天該班的科目。
   - 點擊「列印交接單」可直接印出 A4 交接單；「複製交接內容」可用於 LINE/郵件通知。
2. **[行政端] admin.html**：出納/行政人員月底結算使用。
   - 具備安全金鑰保護，防止非授權人員讀取薪資個資。
   - 一鍵同步雲端資料，按代課教師分組統計總節數、鐘點費、導師費與實領總額，並能下載當月 JSON 檔。
3. **[雲端後台] google_apps_script.js**：部署於 Google 試算表（Google Sheets）作為資料庫，按月份自動建表儲存。
4. **[本機產生器] generate_voucher.py**：讀取 JSON，自動產生 Word/Excel 印領清冊（符合政府機關核銷格式）。

## 🛠️ 快速部署教學（新學校使用步驟）

### 第一步：準備試算表（資料庫）
1. 建立一個全新的 **Google 試算表**。
2. 建立一個名為 **`Class_Timetables`** 的分頁。
3. 在 `Class_Timetables` 分頁中，設定以下 5 欄標頭（第 1 列）：
   - A 欄：`班級`（例如：一甲、二甲）
   - B 欄：`星期(1-5)`（例如：1, 2, 3, 4, 5）
   - C 欄：`節次`（例如：1, 2, 3, 4, 5, 6, 7）
   - D 欄：`科目`（例如：國語、數學）
   - E 欄：`授課教師`（例如：陳小明）
4. 從第 2 列開始，填入您學校的完整課表。這會用來在老師填表時自動帶入課程。

### 第二步：部署 Google Apps Script
1. 在剛剛建立的試算表中，點選上方選單 **「擴充功能」→「Apps Script」**。
2. 將本專案的 **`google_apps_script.js`** 內容複製，全部覆蓋貼入。
3. 修改程式碼第 29 行的 `SECRET_KEY`：
   `var SECRET_KEY = '自訂一串安全的密碼字串';`（此金鑰將用來保護行政端資料）。
4. 按下儲存。
5. 點選右上角 **「部署」→「新部署」**：
   - 點選齒輪，選擇 **「網頁應用程式 (Web App)」**。
   - **執行身分**：選 **「我」**（您的 Google 帳號）。
   - **誰有存取權**：選 **「所有人 (Anyone)」**（老師免登入填報必備）。
6. 按下部署後，**複製產生的「網頁應用程式 URL」**。

### 第三步：設定網頁端（教師端 & 行政端）
將網頁檔案提供給使用者，可直接以瀏覽器雙擊開啟（本機執行），或上傳至 GitHub Pages 等靜態網站代管。

#### 1. 填報教師端 (`teacher.html`)
- 打開網頁，點選右上角 **「齒輪」** 設定圖示。
- 貼入剛複製的 **Web App URL** 並儲存。
- （如果要發布在 GitHub Pages 給全校用，可直接修改 `teacher.html` 原始碼中的 `DEFAULT_GAS_URL` 常數，讓老師們不用手動設定）。

#### 2. 行政核銷端 (`admin.html`)
- 打開網頁，點選右上角 **「齒輪」** 設定圖示。
- 貼入 **Web App URL** 以及您在 Apps Script 設定的 **金鑰（SECRET_KEY）** 後儲存。
- 選擇結算月份後，系統便會自動將資料同步下來。

## 📄 印領清冊產生器使用指南

1. 在行政端網頁中確認當月資料無誤後，點選 **「下載當月結算 JSON」**。
2. 將下載的 `代課費系統備份_YYYY-MM.json` 與本資料夾的 `generate_voucher.py` 放在同一個目錄下。
3. 確保同目錄下有 Excel 格式範本 `印領清冊113.xlsx`。
4. 打開終端機或命令提示字元，執行：
   ```bash
   python generate_voucher.py
   ```
5. 照著畫面提示操作，即可自動產出：
   - `YYYY年MM月_代課費印領清冊.docx`（A4 橫式 Word 檔，含總表、代班詳細明細）
   - `115年MM月_代課費印領清冊.xlsx`（自動帶入統計數據的 Excel 報表）

## 🔒 安全性說明
- **資料不會外流**：資料庫完全架設在您個人的 Google 雲端硬碟，除了擁有金鑰密碼的行政人員外，沒有人能讀取您的代課費資料。
- **請保護好您的金鑰**：不要將內含真實金鑰的 `google_apps_script.js` 上傳至公開的 GitHub 儲存庫。
