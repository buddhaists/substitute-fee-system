# 國小代課費計算與管理系統 (Google Apps Script Web App 雲端全整合版)

這是一套專為國小/國中/高中學校教務處與教師設計的**「代課費計算與管理系統」**。
全系統採用 **前端網頁（首頁、教師端、行政端、CSS 樣式）與後端試算表資料庫一體化整合架構**，運行於 Google Apps Script (GAS) 雲端平台。

只需在 Google 試算表中建立 Apps Script 專案並進行「網頁應用程式部署」，即可獲得專屬雲端系統網址，老師與行政人員直接點開網址即可操作，免架站、免伺服器、支援跨平台與手機/平板/電腦操作！

## 🌟 核心功能特色

### 1. 🏫 教師交接端 (`?page=teacher`)
* **基本交接資訊自選**：
  * **起訖日期自由選取**：支援單日或自選多日連續代課（系統自動排除週六日），可一鍵批次送出多天交接單。
  * **全域設定動態帶入**：學校名稱、鐘點費率由系統設定直接抓取並即時顯示。
  * **代課教師預設空白**：符合實際填報流程，由填單者輸入或指派。
  * **班級與請假教師雙向智慧連動**：從 `Class_Timetables` 分頁即時讀取全校班級（支援數字班級如 `101`、`102` 或傳統班級 `一甲`、`二甲`）與教師清單，選定後自動帶入當天課表並自動勾選任課節次。
* **整天代理（導師費模式）**：勾選「整天代理」時，自動一鍵全選左側早修、打掃、1~7 節課表、午餐、午休、放學等所有作息項目。
* **A4 紙本通知單一鍵列印**：填寫完成即可直接預覽並列印標準橫式 A4 代課交接事項通知單。
* **雲端一鍵送出**：直接將交接單與代課紀錄儲存至 Google 試算表。

### 2. 📊 行政核銷端 (`?page=admin`)
* **月度代課節數與費用自動結算**：自動彙整當月所有代課紀錄，統計節數、鐘點費、導師費與總金額。
* **✏️ 網頁端線上編輯 / 🗑️ 單筆與批次刪除**：在行政介面可直接線上即時修改或刪除代課紀錄，立即回寫更新試算表。
* **系統全域參數設定 (`System_Settings`)**：
  * 線上自訂學校名稱、學層鐘點費率、每日作息時段。
  * **系統運作與網管維護人員設定**：自訂維護窗口職稱與姓名（例如：資訊執秘 蔡志益）。
  * **全校課表批次匯入與線上矩陣檢視**：支援由 Excel/CSV 貼上課表快速匯入至 `Class_Timetables`。
* **🔒 雙重安全金鑰密碼保護**：
  * 進入全校參數設定介面前需先輸入管理密碼。
  * 修改系統參數與維護人員資料時需再次輸入密碼驗證。
  * 密碼完美支援開頭為 `0` 的任意字串（例如 `087525402`）。
* **核銷報表與資料備份**：支援匯出 Excel 報表與下載核銷 JSON 檔，搭配本機腳本產生印領清冊。

### 3. 🛡️ 全域頁尾維護資訊
* 在全系統所有頁面（入口首頁、教師交接端、行政核銷端）下方，統一即時顯示學校名稱與系統運作/網管維護人員資訊。

## 📁 專案檔案清單（GAS 對應檔案）

在 Google Apps Script 編輯器中，請建立以下檔案並貼入對應內容：

| 檔案名稱 | GAS 檔案類型 | 功能說明 |
| :--- | :--- | :--- |
| **`Code.gs`** | 程式碼檔 (.gs) | 後台資料庫邏輯、Web App 路由 (`doGet`/`doPost`)、直連 API、Cache 快取與試算表讀寫 |
| **`index.html`** | HTML 檔 (.html) | **系統入口門戶**（已內嵌完整 CSS，含教師端與行政端選單入口、頁尾維護資訊） |
| **`teacher.html`** | HTML 檔 (.html) | **教師交接端**（起訖日期自選、課表班級連動、整天代理全選、A4 紙本列印） |
| **`admin.html`** | HTML 檔 (.html) | **行政核銷端**（月度結算、線上編輯刪除、系統設定、課表管理、金鑰安全驗證） |

*(本機輔助檔案)*：
* `styles.html` / `styles.css`：CSS 原始樣式備份。
* `generate_voucher.py`：本機 Word (.docx) / Excel (.xlsx) 核銷印領清冊自動生成腳本。
* `印領清冊113.xlsx`：核銷報表 Excel 格式範本。

## 🚀 快速部署步驟（3 分鐘完成）

### 第一步：建立 Google 試算表分頁
1. 開啟您的 Google 雲端硬碟，新增一份「Google 試算表」。
2. 在試算表下方建立以下基礎分頁：
   * **`Class_Timetables`**（課表分頁）：
     * **A 欄**：班級（例：`101`、`102` 或 `一甲`、`四甲`）
     * **B 欄**：星期（例：`1`、`2`、`3`、`4`、`5`）
     * **C 欄**：節次（例：`1`、`2`、`3`、`4`、`5`、`6`、`7`）
     * **D 欄**：科目（例：`國語101`、`數學101`）
     * **E 欄**：授課教師（例：`AAA`、`BBB`、`楊琬瑄`）
   * **`System_Settings`**（系統全域設定分頁，首次儲存設定時會由系統自動建立）。

---

### 第二步：建立 Apps Script 檔案並貼入程式碼
1. 在 Google 試算表上方選單，點選 **「擴充功能」➔「Apps Script」**。
2. 在左側「檔案」清單中建立並貼上以下檔案：
   * 點選預設的 `程式碼.gs`（重新命名為 `Code.gs`），**貼上本專案的 `Code.gs` 內容**。
   * 點選 **「+」➔「HTML」**，輸入檔名 **`index`**，**貼上本專案的 `index.html` 內容**。
   * 點選 **「+」➔「HTML」**，輸入檔名 **`teacher`**，**貼上本專案的 `teacher.html` 內容**。
   * 點選 **「+」➔「HTML」**，輸入檔名 **`admin`**，**貼上本專案的 `admin.html` 內容**。
3. 點選上方工具列的 **「儲存」圖示 (Ctrl + S)**。

---

### 第三步：發布部署為網頁應用程式 (Web App)
1. 點擊右上角藍色按鈕 **「部署」➔「新增部署」**（若已部署過請選「管理部署」➔ 鉛筆「編輯」➔ 版本選「新版本」）。
2. 點擊齒輪圖示，選取 **「網頁應用程式」** (Web App)。
3. 設定如下：
   * **說明**：代課費計算與管理系統
   * **執行身分**：選取 **「我」 (Me)**
   * **誰有存取權**：選取 **「所有人」 (Anyone)** *(確保全校教師免登入即可填報)*
4. 點擊 **「部署」**，依畫面提示完成 Google 帳號授權。
5. 複製系統產生的 **「網頁應用程式網址」** (URL)。

## 📄 印領清冊產生器使用說明

1. 在行政端確認資料無誤後，點選 **「下載當月結算 JSON」**。
2. 將下載的 `代課費系統備份_YYYY-MM.json` 放置於本機專案資料夾下（與 `generate_voucher.py`、`印領清冊113.xlsx` 同一目錄）。
3. 執行 Python 腳本：
   ```bash
   python generate_voucher.py
   ```
4. 系統將自動產出：
   * `YYYY年MM月_代課費印領清冊.docx` (橫式 A4 Word 清冊，可直接列印簽章核銷)
   * `115年MM月_代課費印領清冊.xlsx` (帶入統計數據的 Excel 報表)
