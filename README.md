# 國小代課費計算與管理系統 (Substitute Teacher Fee & Handover Management System)

這是一套專為國小教務處與教師設計的**「代課費計算與管理系統」**。系統旨在簡化教師請假時的交接流程、自動化月底的代課費用統計，並能一鍵產生符合政府機關核銷格式的 Word/Excel 代課費印領清冊。

本系統採用**前後端分離**架構，後端完全架設在您個人的 **Google 試算表 (Google Sheets)**，不需要租用伺服器或資料庫，完全免費且能確保教師薪資與個資的私密性。

## ✨ 核心特色

1. 📱 **教師端方便填報**：手機即可直接開啟網頁填寫，自動依學校課表帶入當天該班的科目，免去教師手動輸入的麻煩。
2. 🖨️ **直覺的紙本交接單**：送出後即可一鍵產生標準 A4 直式交代事項通知單，便於列印進行紙本核章。
3. 🔒 **安全密鑰保護**：行政端讀取資料需驗證自訂金鑰（SECRET_KEY），防止敏感的教師姓名與薪資個資在公開網路流出。
4. 📅 **按月自動分頁**：Google 試算表後端會根據代課月份，自動建立獨立的月份頁籤（例如：`2026-07_總表`、`2026-07_明細`），歷史資料整齊不混雜。
5. 💵 **彈性計費模式**：支援「按節代課（每節 405 元）」與「整天代課（改領導師費，後台自行計算）」兩種實務常見模式。
6. 📄 **一鍵自動生成核銷清冊**：行政人員下載結算 JSON 檔後，可利用 Python 腳本直接產出橫向 A4 Word 印領清冊與統計 Excel 報表。

## 🛠️ 快速部署指南

本系統由以下檔案組成：
* `teacher.html`：教師端填報與交接單列印頁面
* `admin.html`：行政端月底同步與結算頁面
* `google_apps_script.js`：Google 試算表後端程式碼
* `generate_voucher.py`：本機 Word/Excel 核銷文件產生器

### 第一步：建立 Google 試算表資料庫
1. 開啟您的 Google 試算表範本（點選「檔案」➔「建立副本」）。
2. 確保試算表內包含名為 `Class_Timetables` 的分頁，並填入您學校的課表。課表格式如下：
   * **A 欄**：班級（例：一甲、二甲）
   * **B 欄**：星期(1-5)（例：1、2、3、4、5）
   * **C 欄**：節次（例：1、2、3、4、5、6、7）
   * **D 欄**：科目（例：國語、數學）
   * **E 欄**：授課教師（例：戴綿綿）

### 第二步：部署 Google Apps Script 後台
1. 在剛剛建立的試算表中，點選上方選單 **「擴充功能」➔「Apps Script」**。
2. 將本專案的 [google_apps_script.js](google_apps_script.js) 內容完整複製，覆蓋貼入 Apps Script 編輯器中。
3. 在程式碼第 37 行設定您的安全金鑰：
   ```javascript
   var SECRET_KEY = '請在此自訂一串安全的密碼字串';
   ```
4. 點選儲存後，按右上角 **「部署」➔「新增部署」**：
   * **類型選取**：網頁應用程式 (Web App)
   * **專案主管 (執行身分)**：選取「我」
   * **誰有存取權**：選取「所有人 (Anyone)」*(供老師免登入填報)*
5. 按下部署，授權帳號後，**複製產生的「網頁應用程式 URL」**。

### 第三步：設定網頁端
您可以將網頁檔案放置於您的電腦本機執行，或部署至 GitHub Pages 等免費網頁空間。
1. **設定教師端**：
   * 打開 `teacher.html`，點選右上角 **「齒輪」**，貼上您複製的 Web App URL 並儲存。
   *(您也可以直接修改 `teacher.html` 中的 `DEFAULT_GAS_URL` 常數，方便發布後老師不需手動設定)*
2. **設定行政端**：
   * 打開 `admin.html`，點選右上角 **「齒輪」**，貼上 Web App URL 以及您在第二步設定的 `SECRET_KEY` 金鑰後儲存。
   * 選擇結算月份後，點擊「從雲端同步資料」，即可同步該月已核銷的代課明細。

## 📄 印領清冊產生器使用說明

1. 在行政端網頁確認當月資料無誤後，點選 **「下載當月結算 JSON」**。
2. 將下載的 `代課費系統備份_YYYY-MM.json` 檔案放置於專案資料夾下，並確保同目錄下有 Excel 範本 `印領清冊113.xlsx` 以及 `generate_voucher.py`。
3. 在終端機 (Terminal) 中執行：
   ```bash
   python3 generate_voucher.py
   ```
4. 照著畫面提示操作，系統將會自動在同目錄下生成：
   * `YYYY年MM月_代課費印領清冊.docx` (橫式 A4 Word，含總表與詳細明細，可直接列印簽章核銷)
   * `115年MM月_代課費印領清冊.xlsx` (帶入統計數據的 Excel 報表)
